# Ney Dream Nail Art Studio Website 💅✨

Website reservasi dan informasi untuk Ney Dream Nail Art Studio. Dibangun menggunakan PHP native dengan desain modern dan responsif.

## Fitur Unggulan:
- 🖋️ **Reservasi Online**: Sistem booking jadwal kuku yang terintegrasi.
- 🤖 **AI Assistant**: Chatbot pintar untuk menjawab pertanyaan seputar layanan.
- 📋 **Riwayat Transaksi**: User bisa melihat riwayat reservasi mereka.
- 📊 **Dashboard Admin**: Manajemen reservasi, feedback, dan user yang komprehensif.
- 📱 **Mobile Responsive**: Pengalaman navigasi premium dengan Hamburger Menu.

## Cara Instalasi:
1. Clone repository ini.
2. Import database.sql ke PHPMyAdmin Anda.
3. Salin `config.php.example` menjadi `config.php` dan sesuaikan kredensial database Anda.
4. Jalankan menggunakan XAMPP atau web server pilihan Anda.
